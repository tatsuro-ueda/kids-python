# manage-tasknotes-local

online-python プロジェクトのタスクノート配置ルール。

## 配置先

| 状態 | パス |
|---|---|
| 作業中 | `docs/steering/` |
| 完了 | `docs/steering/done/` |

## ファイル命名

```
YYYYMMDD-{英語ケバブケース}.md
```

例：`20260412-live-chat.md`
